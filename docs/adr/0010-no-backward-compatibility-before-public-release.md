# No backward compatibility before public release

The existing v0.1.x tags are internal development snapshots, not a compatibility contract: yindex has no users and has not been publicly released. The Liquid Glass redesign may replace the Home schema, default Page sequence, Style system, stored media references, and migration code instead of preserving old local data. Backward compatibility begins only once the product is explicitly declared publicly released; until then, correctness and design coherence take priority over migrating development-state data.
