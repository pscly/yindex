# Layout 使用相对视口百分比坐标系

Page 上 Widget Instance 的位置与尺寸（x/y/w/h）以视口宽高的百分比表达与存储，而不是固定 CSS 像素；Widget 允许重叠，并以显式层级（z）控制前后关系。原因：新标签页几乎总是全视口；百分比在窗口缩放时更能保持相对构图，契合「每页一张画布」而不是文档流排版。

## Considered Options

- **视口百分比（采纳）** — 实现与心智简单
- **固定设计画布 + 等比缩放** — 设计稿还原强，极端比例要处理 letterbox
- **绝对 CSS 像素** — 换分辨率易错位
- **混合规则** — 更稳但规则复杂，可后置

## Consequences

- 编辑器与吸附应在同一逻辑坐标下计算，再映射到像素渲染
- Layout 实例数据需保存 z 层级；编辑态提供置顶、置底、上移、下移
- 窗口变化时执行最小尺寸与安全区边界修正；Edit Mode 支持多选对齐，不旋转
